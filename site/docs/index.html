Documentation

Start with Spawnr.

Install the CLI. Download its verified runtime. Create an isolated development machine.

01

Install

Spawnr V1 requires Linux x86_64 and access to /dev/kvm.

shell 
curl -fsSL https://spawnr-cli.dev/install.sh | sh
spawnr setup
spawnr doctor

setup downloads the runtime that matches the CLI. doctor checks your host and the runtime.

02

Create your first machine

Give Spawnr an OCI image and a Git repository.

shell 
spawnr clone \
  ghcr.io/acme/rust-dev:v1 \
  git@github.com:acme/project.git

spawnr open project-1
Image requirements

The image must contain Git. It must also contain an SSH client when you use an SSH repository URL.

03

Use the machine

spawnr ls

List your machines.

spawnr open <name>

Open a shell in a running machine.

spawnr start <name>

Start a stopped machine.

spawnr stop <name>

Stop a machine and keep its data.

spawnr rm <name>

Remove a machine after a workspace check.

Spawnr forwards SSH signing requests to your host agent. It does not copy your private keys. Read the security model before you run untrusted code.

04

Publish the environment

Publish installed tools and system changes as a new OCI image.

shell 
spawnr publish project-1 ghcr.io/acme/rust-dev:v2

Spawnr publishes only the environment disk. It excludes the workspace and session data by design.
